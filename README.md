# online_market

Магазин, в котором можно добавлять товары в корзину и отправлять заявку на подтверждение.

## Описание проекта

Этот проект представляет собой интернет-магазин с базовым пользовательским опытом:

- просмотр товаров;
- добавление товаров в корзину;
- изменение количества товаров в корзине;
- оформление заявки на подтверждение заказа;
- удобный интерфейс для покупателя.

## Основные функции

- Добавление товара в корзину
- Удаление товара из корзины
- Изменение количества товара
- Подсчет общей суммы заказа
- Отправка заявки на подтверждение покупки
- Простая и понятная структура интерфейса

## Запуск проекта

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/SV1Stail/online_market.git
   ```
2. Перейдите в папку проекта:
   ```bash
   cd online_market
   ```
3. Установите зависимости:
   ```bash
   npm install
   ```
4. Запустите приложение:
   ```bash
   npm start
   ```

> Если проект использует другой стек запуска, его необходимо будет уточнить и обновить данный раздел после добавления файлов проекта.
