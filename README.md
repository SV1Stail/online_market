# online_market

Интернет-магазин, в котором покупатели могут выбирать товары, добавлять их в
корзину и отправлять заказ на подтверждение.

## Описание проекта

Проект реализует бэкенд интернет-магазина с публичным каталогом, анонимными
корзинами, оформлением и отслеживанием заказов, а также административным
управлением каталогом и заказами.

## Основные возможности

- просмотр товаров и категорий;
- управление анонимной корзиной;
- идемпотентное оформление заказа;
- получение заказа покупателем по номеру и секретному токену;
- аутентификация администратора;
- изменение состава, названия и статуса заказа;
- управление товарами и категориями;
- история изменений заказов;
- асинхронная отправка уведомлений администратору.

## Технологии

- Go и gRPC для бэкенда;
- PostgreSQL для основных данных;
- Redis для распределённого ограничения частоты запросов;
- Docker и Docker Compose для локального развёртывания и промышленной среды.

## Статус проекта

Проект находится в разработке.
