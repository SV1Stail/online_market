# Go-контракты online_market

Этот отдельный Go-модуль публикует сгенерированные сообщения, gRPC-клиенты
и HTTP handlers. Исходные `.proto` и HTTP mappings находятся в
`../backend/api/proto` и остаются единственным источником контракта.

После изменения контракта из каталога `contracts/` выполните `make generate`.
Команда генерирует Go-код непосредственно в `gen/online_market/v1` и не меняет
артефакты backend. Просмотрите diff и удалите файлы для удалённых сервисов
вручную. Версии генераторов закреплены в `Makefile`.

Публикация модуля требует коммита с обновлённым `contracts/` и отдельного
неизменяемого Git-тега `contracts/vX.Y.Z`. Затем потребители обновляют
`github.com/SV1Stail/online_market/contracts` до этой версии. Не передвигайте
уже опубликованный тег: для следующего изменения выпускайте новую версию.
